# FSDL Lab - 8 Web Development Experiments

This repository contains all 8 web development experiments in separate folders.

1. Experiment 1 - Personal Portfolio using HTML5, CSS Grid and Flexbox
2. Experiment 2 - JavaScript Quiz with Timer and Scoring
3. Experiment 3 - Responsive Blog using Bootstrap 5
4. Experiment 4 - Weather Forecast Dashboard using Fetch API
5. Experiment 5 - React Router Multi-page Site
6. Experiment 6 - React ToDo App using Hooks and Local Storage
7. Experiment 7 - Angular 16 Reactive Contact Form
8. Experiment 8 - Express.js RESTful Book Management API

## Important

Do not commit `node_modules`. Run `npm install` inside Experiments 5, 6, 7 and 8 after extracting the project.
